News

(libfcrypt) Update 1.1.0 released.

Libfcrypt's first update releases 09/29/2026, this brings some big and small changes. Startings with the small changes, __init__.py and base.py are now compliant with Python styling rules thanks to Ruff; additionally, README.md is now also Markdown compliant, thanks to RumDL. As for the headlining feature, a new function was introduced to allow password-derived keys with the use of base.passwd_gen_key() . This update also comes with a version bump in __init__.py .

(libfcrypt) Update 1.2.1 released.

Update 1.2.1 brings several new functions and features. Most of these relate to binary encryption and decryption, but update 1.2.1 also brings a new, crucial function in base.py: base.check_key(), this function ensures all keys passed to other functions are valid. Along with base.check_key() 1.2.1 also introduces a new file errors.py as of right now it only contains one error InvalidKey . As for why it's not update 1.2.0, that's due to a minor issue involving relative imports.
