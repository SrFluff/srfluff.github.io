(libfcrypt) Update 1.1.0 released.

Libfcrypt's first update releases 09/29/2026, this brings some big and small changes. Startings with the small changes, __init__.py and base.py are now compliant with Python styling rules thanks to Ruff; additionally, README.md is now also Markdown compliant, thanks to RumDL. As for the headlining feature, a new function was introduced to allow password-derived keys with the use of base.passwd_gen_key() . This update also comes with a version bump in __init__.py .
