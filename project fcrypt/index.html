Project Fcrypt is a suite of tools written in Python aimed at encrypting data. Backed by the main libfcrypt, this project employs the use of the Python cryptography module, specifically the fernet object and its associated functions.

Project Fcrypt also provides the FET (Fcrypt Encryption Tool) for encrypting strings and files from the command-line. This gives direct, human-friendly, access to the libfcrypt back-end.
