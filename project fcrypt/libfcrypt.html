libfcrypt

Libfcrypt is core to the Fcrypt suite. It provides functions for generating keys, encrypting and decrypting string, and encrypting and decrypting files. Using cryptography.fernet for all its encryption, it contains minimal dependencies. Along with its functions it holds only two variables: VERSION (the module version) and LICENSE (the module license [MIT]). As of version 1.1.0, libfcrypt can generate keys derived from a passphrase.

Libfcrypt can be used through the command-line with the help of FET (Fcrypt Encryption Tool).
